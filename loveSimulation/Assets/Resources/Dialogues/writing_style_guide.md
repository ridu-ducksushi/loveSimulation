# 시나리오 글쓰기 스타일 가이드

> AI 특유의 반복적·평탄한 글쓰기 패턴을 차단하기 위한 SSOT.
> **챕터 작성 직전 참조, 작성 직후 자가점검 루틴 의무.**
> 사용자가 반복 코칭한 패턴을 정형화한 풀. 새 패턴 발견 시 즉시 추가.

---

## 핵심 원칙 — "AI 같아 보이는 글쓰기" 차단

다음은 한국어 웹소설·시나리오의 자연스러운 결을 깨트리는, AI 가 자가점검 없이 자동 반사로 생산하는 패턴들이다. **기본 default = 안 쓴다.** 정당한 자리에만 *제한적으로* 사용.

| 안티패턴 | 문제 |
|---|---|
| em dash "—" 줄마다 박힘 | 모든 문장이 "극적 휴지" 로 평탄화 |
| 말줄임표 "..." 대사 끝마다 | 인물의 망설임이 punctuation 으로 떼워짐 |
| "한 박자"·"한 뼘"·"한 톤" 비유 반복 | 모든 순간이 음악적 박자로 나눠짐 |
| "결" 추상명사 반복 | 묘사 전반에 한 글자 단어가 깔림 |
| 같은 구조 문장 반복 | 모든 narration 이 동일 리듬 |
| 같은 어미 반복 ("~지요~", "~네요~") | 한 인물의 voice 가 단조로워짐 |
| 손/손가락 부위 위주 묘사 | 스킨쉽이 한 부위 군에 몰림 |

---

## 1. Punctuation 자제

### 1-1. em dash "—"

- **기본**: 안 쓴다. 마침표·쉼표·줄바꿈으로 충분.
- **정당화 자리** (한 챕터당 **3~5개 이내**):
  - 말이 *진짜로* 끊긴 순간 (상대 가로막음, 충격)
  - 액션 직전 *진짜* 서스펜스 ("그 순간 —" 후 검명 울림)
- **금지 패턴**:
  - 강조용 ("혐오. 그래, 분명한 혐오야 — 나는...")
  - 부연 설명용 ("낮은 목소리에 — 본인도 당황한 결이...")
  - 줄바꿈 직후 첫 단어 ("...하지만 —)")
  - 끝맺음 회피용 (문장 끝에 "—" 만 붙이고 끝)

### 1-2. 말줄임표 "..."

- **기본**: 자제. 인물의 망설임은 *내용*으로 표현하지 punctuation 으로 떼우지 않음.
- **정당화 자리**:
  - 인물이 *진짜* 말을 흐리는 순간 (충격, 망설임, 알면서도 못 말함)
  - 사고가 *의도적*으로 끊기는 자리
- **금지 패턴**:
  - 모든 내면 독백이 "(...X)" 로 시작 (5회 이상이면 의심, 10회 이상 거의 확실한 남발)
  - 대사 끝마다 "..." ("...괜찮아요...", "...그래도...")
  - 한 라인 안에 "..." 두 번 이상 ("...아... 그건...")
  - 문장 사이 줄바꿈 대신 "..."

## 2. Verbal tic (단어·구 반복) 자제

### 자제 풀

- **시간 비유**: "한 박자", "한 호흡", "한 순간"
- **거리 비유**: "한 뼘", "한 자락", "한 걸음"
- **음향 비유**: "한 톤", "한 단계"
- **추상명사**: "결" (음악적 결, 그 결 등)
  - ✅ 정상 단어 (결혼·결국·숨결·결의(決意)·결론·연결·결코) 는 자제 대상 *아님*

### 대체 표현 풀

| 원래 | 대체 후보 |
|---|---|
| 한 박자 | 잠시 / 잠깐 / 짧게 / 그냥 빼기 |
| 한 박자 길게 | 오래 / 길게 |
| 한 박자 늦게 | 조금 늦게 / 느직하게 |
| 한 뼘 | 조금 좁혀 / 가까이 (측량이 *진짜* 필요할 때만 보존) |
| 한 톤 낮아진 | 낮게 깔린 / 깊어진 |
| 결 | 맥 / 느낌 / 분위기 / 모양새 / 어조 / 그냥 빼기 |

### 정당화 자리 (1~2회)

- 음향 단절 직전 (예: "길드 안이 한 박자 조용해졌다가 —" 다음에 환호 터짐)
- 결정적 트리거 순간 (예: "살갗에 닿은 그 한 박자")
- 측량 거리가 *진짜 핵심 의미* (닿을 듯 닿지 않는 거리)

---

## 3. 반복 문장 패턴 자제

verbal tic 은 단어·구뿐 아니라 *문장 단위* 로도 발생.

### 의심 패턴

- 같은 구조 문장이 챕터 내 여러 번 ("X가 Y했다 → 다른 자리에서 같은 X가 Y했다")
- 같은 톤의 대사가 인물 구분 없이 반복 ("이게 아닌가요?", "...괜찮아요." 류)
- 한 인물의 같은 어미 5회 이상 ("~지요~", "~네요~")
- 동일 메타 묘사 반복 ("그가 잠시 멈췄다", "그의 시선이 머물렀다")
- 모든 narration 이 같은 패턴으로 시작 ("그가...", "그녀가...")

### 대체 전략

- 같은 구조 → 어순 바꾸기, 문장 합치기·분리하기
- 같은 어미 → "~지요~" / "~네요" / "~예요" / "~군요" 다양화
- 같은 메타 묘사 → 부위·동사 변경 (아래 4번 호응)

---

## 4. 스킨쉽 부위 다양화

`character_settings.md` 의 SSOT 와 호응. 손/손가락/손목 군에 몰리는 안티패턴 차단.

### 활용 풀

| 영역 | 부위 |
|---|---|
| 얼굴 | 광대, 이마, 콧날, 입술, 턱 |
| 목 주변 | 귓볼, 귓가, 목덜미, 쇄골, 목선 |
| 상체 | 어깨, 등, 허리, 옆구리 |
| 머리 | 정수리, 머리카락 |
| 기타 | 살갗, 비늘 (에르하 전용) |

손/손가락은 *매개* 로만 사용 ("손가락에 머리카락을 감았다" — 묘사 중심은 머리카락).

### 의심 기준
한 챕터 내 *손/손가락/손목/손등/손바닥* 이 합산 5회 이상이면 부위 분포 재검토.

---

## 5. 작성 직후 자가점검 루틴 (필수)

새 챕터 작성 완료 *직전* 다음 루틴 실행. 사용자 지적 *이전* 에 자가검증으로 잡는 것이 목표.

```bash
F=Assets/Resources/Dialogues/chapter<N>.json

echo "=== Punctuation ==="
echo "em dash: $(grep -c '—' $F)"
echo "말줄임표(...): $(grep -o '\.\.\.' $F | wc -l)"

echo "=== Verbal tic ==="
for w in "한 박자" "한 뼘" "한 톤" "한 호흡"; do
  echo "$w: $(grep -c "$w" $F)"
done

echo "=== 부위 분포 (손 군 집중도) ==="
for w in "손목" "손등" "손바닥" "손가락"; do
  echo "$w: $(grep -c "$w" $F)"
done
```

### 기준치

| 지표 | 자연스러움 | 의심 | 즉시 정정 |
|---|---|---|---|
| em dash | 0~5 | 6~9 | 10+ |
| 말줄임표 (전체) | <30 | 30~50 | 50+ |
| 한 박자 / 단일 verbal tic | 0~4 | 5~6 | 7+ |
| 손 군 합산 | 0~4 | 5~7 | 8+ |

기준치 초과 시 *사용자에게 보고하기 전* 자체 정정.

---

## 6. 메타 원칙

- 이 가이드는 사용자가 반복 코칭한 패턴들의 정형화. **새 패턴 발견 시 즉시 이 파일에 추가**.
- 본질: AI 가 자가점검 못 하고 빠져나가는 글쓰기 패턴 풀 = *비-AI 글쓰기*에 가까워지기 위한 자기 통제 도구.
- "이거 어디서 본 것 같은데" 라는 직감이 들면 *즉시 grep 카운트* — 직감이 거의 항상 맞음.
- 가이드를 따르는 것보다 **가이드가 끊임없이 갱신되는 것** 이 더 중요. AI 의 verbal tic 은 모델 변화·세션 변화에 따라 새로운 군이 생김.
